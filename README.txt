RAJVANSH PUBLIC SENIOR SECONDARY SCHOOL WEBSITE

Option A — Standalone HTML:
Use rajvansh_school_website_standalone.html. All images are embedded into this one file,
so photos will display even if you upload only this HTML file.

Option B — Website folder:
Keep index.html and the assets folder together. Do not move index.html out of its folder.
Open index.html in a browser to preview.

For GitHub Pages / hosting, upload the complete folder contents, including assets/.
Before publishing, replace school@example.com and add the school's verified contact details.
